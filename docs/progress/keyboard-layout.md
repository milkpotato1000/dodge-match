시작·일시정지 화면에 PC 이동 키 선택을 추가했다. 기본 WASD이며 방향키 선택과
재실행 후 저장 복원을 지원한다. 선택한 KeyboardEvent.code만 읽고 다른 키 묶음은
무시한다. 반대 방향 상쇄·대각선 정규화·90U/s는 기존 엔진을 그대로 사용한다.
키 변경·일시정지·포커스 상실·입력 필드 포커스 시 눌림 상태를 비워 이동이 남지 않는다.
플레이 중 선택된 방향키는 스크롤을 차단하고, HTML 입력 중에는 이동을 생성하지 않는다.
플레이 HUD도 선택한 키만 안내한다. 모바일 D-pad와 Match 입력은 유지했다.

검증: 단위 테스트 32개, 브라우저 시나리오 7개, 프로덕션 빌드 및 계약 가드 PASS.
