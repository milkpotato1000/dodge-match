# 반려견 플레이어 캐릭터

사용자가 제공한 반려견 사진과 영상 프레임을 시각 참고로 삼아 ImageGen으로 제작한 Dodge 플레이어 캐릭터 기준 자산이다. 원본 사진, 영상과 임시 추출 프레임은 이 저장소에 포함하지 않는다.

## 현재 외형 보정 — 2026-09-17

사용자 후속 요청으로 **보는 사람 기준 왼쪽 눈 주변과 아래 볼 흰색, 오른쪽 눈 주변 검정, 머리 위 양쪽과 귀 검정**으로 수정했다.
귀는 약간 작게 표현한다. 후속 직접 그리기 기준에 따라 머리 위 양쪽과 귀 연결부는 검정, 가운데 좁은 흰 이마선, 왼쪽 눈 주변과 아래 볼은 흰색으로 유지한다. 검정은 관자놀이 옆으로 내려오며 차콜색 털 결과 보랏빛 음영으로 자연스럽게 연결한다.

현재 기준인 `player-dog-idle-v2.png`와 `player-dog-loading-run-v1.png`는 실제 알파 채널을 포함한다. 로딩 루프는 사용자가 고른 상태 시트의 상단 가운데 뻗은 달리기와 하단 가운데 즐거운 공중 자세를 핵심 프레임으로 삼아 v2 외형과 발 규칙으로 재제작했다. 상태 시트는 자세 참고에만 쓰며, 구현용 `move`, `near-hit`, `hit`, `match-success`, `forbidden-cry`는 v2를 기준으로 개별 투명 PNG로 제작한 뒤 같은 바닥 중심 피벗, 투명 캔버스와 표시 반지름에 맞춘다. 왼쪽 이동은 오른쪽 이동 자산을 수평 반전한다.

## 외형 기준

- 검은색의 길고 늘어진 귀
- 비대칭 검은 눈가 무늬와 좁은 흰 이마선
- 흰 주둥이, 몸과 다리의 작은 검정·회색 점무늬
- 높이 말린 풍성한 흰 꼬리
- 밝은 눈과 혀를 내민 웃는 표정
- 짙은 외곽선, 옅은 보라 그림자, 가는 청록 림라이트
- 발톱과 짙은 발가락 선을 표시하지 않은 흰색의 둥근 발; 필요한 입체감은 옅은 아이보리·연보라 음영만 사용

세부 털보다 귀·얼굴 마스크·꼬리의 큰 실루엣을 우선한다. 렌더 그림은 충돌 판정과 분리하며, 게임 규칙의 표시 반지름 2U와 충돌 반지름 1.5U를 유지한다. 실제 표시는 약 18~22dp를 목표로 한다. 상태별 그림의 자세나 스케일이 달라도 충돌 원의 중심·크기·범위는 공통 바닥 피벗에 고정한다.

## 생성 지시 요약

실제 반려견의 위 식별점을 보존하면서 작은 화면용으로 머리와 꼬리를 약간 키운 밝은 인디 아케이드 마스코트로 재구성했다. 배경·의상·목걸이·문자·UI를 제외하고 투명 PNG로 만들었으며, 다섯 동작은 같은 무늬·비율·팔레트·선 굵기를 유지하도록 지시했다.
