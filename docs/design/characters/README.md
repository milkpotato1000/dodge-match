# 반려견 플레이어 캐릭터 v1

사용자가 제공한 반려견 사진과 영상 프레임을 시각 참고로 삼아 ImageGen으로 제작한 Dodge 플레이어 캐릭터 기준 자산이다. 원본 사진, 영상과 임시 추출 프레임은 이 저장소에 포함하지 않는다.

## 자산

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `player-dog-idle-v1.png` | 1254×1254 RGBA | 기본 플레이·축소 판독성의 기준 마스터 |
| `player-dog-state-sheet-v1.png` | 1536×1024 RGBA | idle, 좌·우 이동, near-hit, match-success 동작 기준 |

두 PNG 모두 실제 알파 채널을 포함한다. 상태 시트는 3×2 개념 셀 중 오른쪽 아래를 비워 두었다. 구현 단계에서는 셀을 그대로 런타임에서 자르지 말고, 각 실루엣의 투명 여백을 기준으로 개별 프레임을 내보낸 뒤 같은 피벗과 표시 반지름에 맞춘다.

## 외형 기준

- 검은색의 길고 늘어진 귀
- 비대칭 검은 눈가 무늬와 좁은 흰 이마선
- 흰 주둥이, 몸과 다리의 작은 검정·회색 점무늬
- 높이 말린 풍성한 흰 꼬리
- 밝은 눈과 혀를 내민 웃는 표정
- 짙은 외곽선, 옅은 보라 그림자, 가는 청록 림라이트

세부 털보다 귀·얼굴 마스크·꼬리의 큰 실루엣을 우선한다. 렌더 그림은 충돌 판정과 분리하며, 게임 규칙의 표시 반지름 3U와 충돌 반지름 2.25U를 유지한다.

## 생성 지시 요약

실제 반려견의 위 식별점을 보존하면서 작은 화면용으로 머리와 꼬리를 약간 키운 밝은 인디 아케이드 마스코트로 재구성했다. 배경·의상·목걸이·문자·UI를 제외하고 투명 PNG로 만들었으며, 다섯 동작은 같은 무늬·비율·팔레트·선 굵기를 유지하도록 지시했다.
