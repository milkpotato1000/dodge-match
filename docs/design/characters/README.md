# 반려견 플레이어 캐릭터

사용자가 제공한 반려견 사진과 영상 프레임을 시각 참고로 삼아 ImageGen으로 제작한 Dodge 플레이어 캐릭터 기준 자산이다. 원본 사진, 영상과 임시 추출 프레임은 이 저장소에 포함하지 않는다.

## 자산

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `player-dog-idle-v2.png` | 1254×1254 RGBA | 현재 기본 플레이·축소 판독성 기준 마스터 |
| `player-dog-idle-v1.png` | 1254×1254 RGBA | 이전 외형 기록; dev에서 사용하지 않음 |
| `player-dog-state-sheet-v1.png` | 1536×1024 RGBA | 동작·자세 참고용; 발 표현은 v2 규칙으로 재제작 |
| `player-dog-forbidden-cry-v1.png` | 1254×1254 RGBA | 울음 표정·자세 참고용; 발 표현은 v2 규칙으로 재제작 |

현재 기준인 `player-dog-idle-v2.png`는 실제 알파 채널을 포함한다. 상태 시트는 자세 참고에만 쓰며, 구현용 `move`, `near-hit`, `hit`, `match-success`, `forbidden-cry`는 v2를 기준으로 개별 투명 PNG로 제작한 뒤 같은 바닥 중심 피벗, 투명 캔버스와 표시 반지름에 맞춘다. 왼쪽 이동은 오른쪽 이동 자산을 수평 반전한다.

## 외형 기준

- 검은색의 길고 늘어진 귀
- 비대칭 검은 눈가 무늬와 좁은 흰 이마선
- 흰 주둥이, 몸과 다리의 작은 검정·회색 점무늬
- 높이 말린 풍성한 흰 꼬리
- 밝은 눈과 혀를 내민 웃는 표정
- 짙은 외곽선, 옅은 보라 그림자, 가는 청록 림라이트
- 발톱과 짙은 발가락 선을 표시하지 않은 흰색의 둥근 발; 필요한 입체감은 옅은 아이보리·연보라 음영만 사용

세부 털보다 귀·얼굴 마스크·꼬리의 큰 실루엣을 우선한다. 렌더 그림은 충돌 판정과 분리하며, 게임 규칙의 표시 반지름 2U와 충돌 반지름 1.5U를 유지한다. 실제 표시는 약 18~22dp를 목표로 한다. 상태별 그림의 자세나 스케일이 달라도 충돌 원의 중심·크기·범위는 공통 바닥 피벗에 고정한다.

## 생성 지시 요약

실제 반려견의 위 식별점을 보존하면서 작은 화면용으로 머리와 꼬리를 약간 키운 밝은 인디 아케이드 마스코트로 재구성했다. 배경·의상·목걸이·문자·UI를 제외하고 투명 PNG로 만들었으며, 다섯 동작은 같은 무늬·비율·팔레트·선 굵기를 유지하도록 지시했다.
