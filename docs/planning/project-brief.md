# Dodge Match 기획 개요

- 작성일: 2026-09-16
- 상태: 첫 구현 기준선 작성 완료 / dev 채택 준비
- 상세 규칙: [동시 플레이 게임 기획](gameplay.md)

## 게임의 한 문장

한 영역에서 반사 이동하는 야구공을 피하면서, 다른 영역에서는 캐릭터가 현재 서 있는 구역과 다른 색의 원을 정확한 타이밍에 터치하는 동시 플레이 게임이다.

동체시력, 시선 전환, 색 구분, 두 조작의 동시 수행을 핵심 경험으로 삼는다. 회피 이동에 따라 금지색이 바뀌므로 두 게임은 규칙으로 연결된다.

## 사용자 지정 방향

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 기본 규격 | 모바일·PC 공통 가로, 50:50 좌우 분할 | 확정 |
| 초기 로딩 | 필수 자산 로딩이 150ms를 넘으면 진행 바 끝을 달리는 강아지와 실제 `n%` 표시, 빠른 캐시 로드는 연출 생략 | 첫 구현 기준선 |
| 회피 오브젝트 | 아이보리 몸체·남청/회색 봉제선의 중성 야구공, 원형 1.6U 판정과 결정론적 정반사 유지 | 첫 구현 기준선 |
| 영역 순서 | 기본 Dodge 왼쪽 / Match 오른쪽, 시작 전 좌우 교환 가능 | 확정 |
| 회피 조작 | 모바일은 Dodge 바깥쪽 하단 모서리의 고정 4방향 D-pad, PC는 WASD/방향키; 양쪽 모두 8방향·고정 90U/s | 확정 |
| 회피 난이도 | 야구공 3→32개, 속도 18→65U/s로 증가 | 상향된 첫 구현 기준선 |
| 색 구역 | 0/30/60/90초에 단색→2색→3색→4색 | 첫 구현 기준선 |
| 반복 색 전환 | 4색 이후 칸별 10초 타이머; 처음에는 동시, 금지색 오입력이 난 칸만 터치 시각 기준으로 분리, 중복색 허용 | 요구사항 |
| 타이밍 조작 | 링이 원 테두리에 닿는 순간을 중심으로 `Perfect / Great / Good / Miss` 판정 | 첫 구현 기준선 |
| Match 생명 | `Miss` 연속 시 감소량 증가, `Good` 중립, `Great/Perfect` 연속 시 회복량 증가 | 첫 구현 기준선 |
| 금지색 | 캐릭터가 현재 서 있는 구역의 색 하나 | 사용자 명시 확정 |
| 금지색 터치 페널티 | `Miss(FORBIDDEN)` 원이 잠긴 Dodge 칸 하나만 즉시 재추첨; 다른 칸과 중복 허용, 해당 칸만 별도 10초 타이머로 분리 | 사용자 명시 확정 |
| 경계 판정 | 0.125U 십자 헤어라인과 캐릭터 바닥 피벗으로 색 결정, 선을 완전히 넘는 스텝에 조명·배지·HUD 동시 전환 | 첫 구현 기준선 |
| 생성 제한 | 차트의 동기 색 전환 직전 0.5초 동안만 원 생성 금지; 입력으로 분리된 칸 타이머에는 적용하지 않음 | 요구사항 |
| Match 난이도 | 정답 간격은 최소 0.625초, 링 수축은 최소 1초까지 각각 빨라지며 동시 원은 최대 4개 | 첫 구현 기준선 |
| 소리 없는 플레이 | 링과 원 테두리의 시각적 일치만으로 모든 판정 가능 | 사용자 명시 확정 |
| 음악 설정 | 음악 켜기/끄기 저장, 음소거 상태에서도 동일한 차트 | 확정 |
| 음악·차트 | 첫 경쟁 차트 120 BPM·180초, 무음에서도 같은 차트 진행 | 첫 구현 기준선 |
| 디자인 제작 | 캐릭터·인터페이스·색·판정·게임 오버의 첫 기준은 [디자인 플랜](visual-design.md) 참고 | 구현 기준선; 최종 자산 후속 |
| Dodge 바닥 | 구역색에 대응하는 Match 문양 하나를 톤온톤으로 크게 각인; `×`·`+`와 궤도선·대각선·비네트 등 다른 장식 음영은 사용하지 않음 | 비주얼 기준선 |
| 플레이어 캐릭터 | 사용자 반려견 특징을 반영한 작은 투명 PNG 캐릭터; 모든 모션에서 공통 피벗과 고정 원형 충돌 범위 사용 | v2 기본 자산 제작 완료; 상태별 자산 후속 |
| 플레이어 경쟁 | 첫 구현은 로컬 비동기 순위, QA 이후 온라인 리더보드 | 범위 확정 |
| 점수 | 생존 시간과 콤보가 적용된 Match 점수를 합산하며 차트별 만점 존재 | 첫 구현 기준선 |

## 이번 기획 범위

두 게임의 연결 규칙, 화면과 입력 흐름, 난이도 증가, 색 전환 및 타이밍 판정을 정리한다. 반려견 기반 첫 캐릭터 기준 자산까지 포함하며, 런타임 구현과 음악 제작은 dev 작업으로 넘긴다.

## 남은 결정

1. 첫 곡의 실제 음원과 최종 시각 디자인.
2. 플레이 테스트 후 난이도·판정·생명·점수 수치 조정.

현재 수치는 첫 구현 기준이며 QA 결과로 조정할 수 있다. 개발 착수와 변경 절차는 [개발 인계 계약](development-contract.md)에 따른다.
