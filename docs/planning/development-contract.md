## 인수 기준

| ID | 사전 조건 | 플레이어 행동 또는 발생 사건 | 기대 결과 | 검증 방법 |
| --- | --- | --- | --- | --- |
| AC-01 | 가로 지원 화면 | 게임 시작 | Dodge 왼쪽, Match 오른쪽의 50:50 화면과 3초 카운트다운 표시 | 모바일·PC 수동 확인 |
| AC-02 | 좌우 교환 설정 | 교환 후 게임 시작 | Match 왼쪽, Dodge 오른쪽이며 모든 입력·표시 좌표도 교환 | 양쪽 배치 입력 검사 |
| AC-03 | 모바일 플레이 | Dodge 포인터를 유지하며 다른 포인터로 Match 입력 | 캐릭터 이동과 원 판정이 동시에 동작하고 포인터 역할이 바뀌지 않음 | 두 손가락 실제 기기 검사 |
| AC-04 | PC 플레이 | WASD/방향키와 마우스를 동시에 사용 | Dodge 이동과 Match 판정이 동시에 동작 | 키보드·마우스 검사 |
| AC-05 | Dodge 진행 | 0~180초 차트 재생 | 점 개수·속도가 정의된 곡선을 따라 증가하고 상한 22개·65U/s를 넘지 않음 | 시각별 상태 로그 비교 |
| AC-06 | Dodge 충돌 | 캐릭터와 점의 충돌 영역 접촉 | 같은 시뮬레이션 스텝에 `dodge_collision` 게임오버 | 경계·고속 통과 자동 검사 |
| AC-07 | Match 판정 | T 기준 −60/−120/−200ms와 경계 주변 입력 | 정의된 경계 포함 규칙대로 Perfect/Great/Good/Miss 판정 | 가상 시계 단위 검사 |
| AC-08 | 금지색 판정 구간 | T−200ms에 원 색과 캐릭터 구역색 일치 | 상태가 금지로 잠기고 미터치 시 Perfect, 터치 시 Miss | 위치·입력 조합 검사 |
| AC-09 | Match 생명 | 판정 연속 입력 | Good 중립, Great/Perfect 회복 콤보, Miss 연속 감소가 표와 일치 | 판정 시퀀스 단위 검사 |
| AC-10 | Match 실패 | 생명이 0에 도달 | 즉시 `match_depleted` 게임오버 | 감소 경계 검사 |
| AC-11 | 색 단계 | 0/30/60/90초 및 100초 이후 10초 간격 도달 | 1/2/3/4구역과 반복 재추첨, 3초 예고 표시 | 가상 시계 검사 |
| AC-12 | 색 전환 | 전환 직전·직후 | 마지막 0.5초 새 원 없음, 기존 원은 유지, 잠긴 상태와 이벤트 순서가 정의대로 유지 | 차트 검증 및 시각 검사 |
| AC-13 | 점수 콤보 | Good/Great/Perfect/Miss 시퀀스 입력 | 기본점수·배율·콤보 초기화가 일치하고 첫 차트 만점이 39,375점 | 표 기반 단위 검사 |
| AC-14 | 차트 완료 | 실패 없이 180초 도달 | `chart_complete` 클리어와 최종 점수·통계·시드 저장 | 가속 시계 통합 검사 |
| AC-15 | 일시정지 | 백그라운드 이동 후 복귀 | 시간 점프·자동 Miss 없이 3초 뒤 같은 시각에서 재개 | 모바일·데스크톱 검사 |
| AC-16 | 무음 | 음량 0으로 전체 플레이 | 시각만으로 모든 판정과 결과 확인 가능하며 점수는 유음과 동일 | 동일 입력 재생 비교 |
| AC-17 | 난수 재현 | 같은 차트·규칙·시드로 재실행 | 원 색과 위치가 같은 순서로 생성 | 결정론 자동 검사 |
| AC-18 | 로컬 기록 | 게임오버 또는 클리어 | 이름, 점수 구성, 판정, 생존 시간, 종료 사유와 시드 저장·재조회 | 저장소 통합 검사 |
