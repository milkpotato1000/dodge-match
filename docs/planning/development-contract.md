## 인수 기준

| ID | 사전 조건 | 플레이어 행동 또는 발생 사건 | 기대 결과 | 검증 방법 |
| --- | --- | --- | --- | --- |
| AC-01 | 가로 지원 화면 | 게임 시작 | Dodge 왼쪽, Match 오른쪽의 50:50 화면과 3초 카운트다운 표시 | 모바일·PC 수동 확인 |
| AC-02 | 좌우 교환 설정 | 교환 후 게임 시작 | Match 왼쪽, Dodge 오른쪽이며 모든 입력·표시 좌표도 교환 | 양쪽 배치 입력 검사 |
| AC-03 | 모바일 플레이 | 외곽 하단 D-pad를 누른 채 다른 포인터로 Match 입력 | D-pad는 8방향·고정 90U/s로 이동하고 원 판정이 동시에 동작하며 포인터 역할이 바뀌지 않음 | 두 손가락 실제 기기·대각선 속도 검사 |
| AC-04 | PC 플레이 | WASD/방향키와 마우스를 동시에 사용 | 모바일과 같은 8방향·고정 90U/s Dodge 이동과 Match 판정이 동시에 동작 | 키보드·마우스·대각선 속도 검사 |
| AC-05 | Dodge 진행 | 0~180초 차트 재생 | 점 개수·속도가 정의된 곡선을 따라 증가하고 상한 32개·65U/s를 넘지 않음 | 시각별 상태 로그 비교 |
| AC-06 | Dodge 충돌 | 캐릭터와 점의 충돌 영역 접촉 | 고정된 캐릭터 1.5U·점 1.6U 원이 닿는 같은 시뮬레이션 스텝에 `dodge_collision` 게임오버 | 경계·고속 통과 자동 검사 |
| AC-07 | Match 판정 | T 기준 −60/−120/−200ms와 경계 주변 입력 | 정의된 경계 포함 규칙대로 Perfect/Great/Good/Miss 판정 | 가상 시계 단위 검사 |
| AC-08 | 금지색 판정 구간 | T−200ms에 원 색과 캐릭터 구역색 일치 | 상태가 금지로 잠기고 미터치 시 Perfect, 터치 시 Miss | 위치·입력 조합 검사 |
| AC-09 | Match 생명 | 판정 연속 입력 | Good 중립, Great/Perfect 회복 콤보, Miss 연속 감소가 표와 일치 | 판정 시퀀스 단위 검사 |
| AC-10 | Match 실패 | 생명이 0에 도달 | 즉시 `match_depleted` 게임오버 | 감소 경계 검사 |
| AC-11 | 색 단계 | 0/30/60/90초 및 100초 이후 10초 간격 도달 | 1/2/3/4구역과 반복 재추첨, 3초 예고 표시 | 가상 시계 검사 |
| AC-12 | 색 전환 | 전환 직전·직후 | 마지막 0.5초 새 원 없음, 기존 원은 유지, 잠긴 상태와 이벤트 순서가 정의대로 유지 | 차트 검증 및 시각 검사 |
| AC-13 | 점수 콤보 | Good/Great/Perfect/Miss 시퀀스 입력 | 기본점수·배율·콤보 초기화가 일치하고 첫 차트 만점이 39,375점 | 표 기반 단위 검사 |
| AC-14 | 차트 완료 | 실패 없이 180초 도달 | `chart_complete` 클리어와 최종 점수·통계·시드 저장 | 가속 시계 통합 검사 |
| AC-15 | 일시정지 | 백그라운드 이동 후 복귀 | 시간 점프·자동 Miss 없이 3초 뒤 같은 시각에서 재개 | 모바일·데스크톱 검사 |
| AC-16 | 무음 | 음량 0으로 전체 플레이 | 시각만으로 모든 판정과 결과 확인 가능하며 점수는 유음과 동일 | 동일 입력 재생 비교 |
| AC-17 | 난수 재현 | 같은 차트·규칙·시드로 재실행 | Match 원의 색·위치와 Dodge 점의 생성 위치·진행각·전체 궤적이 동일 | 결정론 자동 검사 |
| AC-18 | 로컬 기록 | 게임오버 또는 클리어 | 이름, 점수 구성, 판정, 생존 시간, 종료 사유와 시드 저장·재조회 | 저장소 통합 검사 |
| AC-19 | 음악 설정 | 플레이 중 음악을 끄고 같은 입력 재생 | 배경 음악만 꺼지고 차트 시간·판정·점수는 동일하며 재실행 후 설정 유지 | 설정·리플레이 검사 |
| AC-20 | 경계 판정 | 공통 바닥 피벗을 0.125U 십자 헤어라인 양쪽과 내부에서 미세 이동 | 선 안에서는 직전 색 유지, 반대편 가장자리를 벗어난 첫 고정 스텝에 조명·캐릭터 위 배지·HUD·금지색이 함께 전환 | 경계 중심±0.0625U 좌표와 60Hz 스텝 단위 검사 |
| AC-21 | 캐릭터 자산 교체 | `player-dog-idle-v2.png`와 v2 규칙의 상태별 투명 PNG를 dev 자산으로 반영 | 반려견 캐릭터가 발톱·짙은 발가락 선 없이 2U 표시 범위·1.5U 충돌 판정으로 표시됨 | 알파·22/96px 축소 판독성·자산 교체 회귀 검사 |
| AC-22 | 캐릭터 상태 전환 | 모든 캐릭터 모션과 상태를 순서대로 재생 | 상태·프레임·회전·표시 스케일과 무관하게 충돌 중심은 공통 바닥 피벗, 반지름은 1.5U로 유지 | 상태별 충돌 원 좌표·반지름 스냅샷 비교 |
| AC-23 | Dodge 벽 반사 | 점을 수평·수직 벽과 모서리에 여러 각도·속도로 충돌 | 입사각=반사각, 속력 유지, 해당 법선 성분만 반전되며 난수·각도 흔들림이 없음 | 고정 시간 스텝과 가변 프레임률의 벡터·궤적 비교 |
| AC-24 | 플레이필드 정보 정리 | 4색 Dodge 단계와 Match 원을 함께 표시 | Dodge 바닥에는 문양·큰 기호가 없고 영역 제목도 없으며, 색 기호는 Match 원·캐릭터 위 배지·HUD 칩에만 표시 | v12 기준 화면과 요소 표시 여부 비교 |
