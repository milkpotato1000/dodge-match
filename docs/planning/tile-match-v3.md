# 16칸 색 일치 보너스 v3

2026-09-17 사용자 직접 요청으로 승인된 변경. 금지색 미터치·잠금·페널티,
단계별 구역 증가와 주기적 색 변경 계약을 대체한다. 난이도 v2의 240초,
247개 차트, 야구공9~96개·23.4~84.5U/s와 캐릭터63U/s는 유지한다.

- 시작부터 4×4=16칸. 각 칸을 7색에서 독립·균등 추첨하며 중복 허용.
- 모든 Match 원은 눌러야 한다. 미터치는 색과 무관하게 Miss. 자동 Perfect와 금지색은 삭제.
- 정상 시간 판정의 Good/Great/Perfect는 기존 콤보·생명 처리를 따른다.
- 클릭 순간의 캐릭터 바닥 피벗이 밟은 칸 색과 원 색이 같으면,
  `round(기본점수 × 갱신된 콤보 배율) × 2`를 지급한다.
- 색이 다르면 정상 판정·콤보와 일반 점수. 너무 이르거나 늦은 Miss에는 2배·재추첨 없음.
- T−200ms 색 잠금은 삭제. 클릭 위치로 결정하며 헤어라인 내부는 직전 칸 유지.
- 색 일치 성공한 그 칸만 즉시 7색 균등 재추첨. 직전 색 재등장과 다른 칸과 중복 모두 허용.
- 같은 스텝의 여러 클릭도 도착 순으로 판정→점수→그 칸 재추첨을 완료한다.
  두 번째 클릭은 첫 클릭으로 바뀐 색을 읽는다. 쿨다운이나 논리적 공백은 없다.
- 시각은 1초 동안 이전 합성색/문양이 사라지고 새 색/문양이 드러나는 교차 페이드.
  터치 시 칸 테두리·짧은 밝기 펄스와 Match의 ×2 피드백 제공.
  연속 성공 시 현재 합성 화면을 시작점으로 다시 페이드. Reduced Effects도 판정 유지.
- 25/50/75U 내부 경계의 0.125U 헤어라인은 물리 벽이 아니다.
- 모든 주기 타이머·SHIFT HUD·PASS/금지 안내는 삭제. 현재 칸과 색 일치 ×2 안내로 교체.
- chartVersion/rulesetVersion=3. 구버전 기록 보존·분리. 이론상 상한은
  247개 모두 Perfect·색 일치 가정의 85,550+24,000=109,550점.
  무작위 배치/이동 제약 때문에 매 시드에서 상한 달성을 보장하지 않는다.

검증: 초기16칸/중복/시간 경과 불변, 16칸 좌표와 경계, 클릭 순간 판정,
일반/2배 점수와 반올림 순서, 미터치 Miss, 성공 칸만 재추첨,
동일 칸 연속·동일 스텝 입력, 같은 색 재추첨, 연속 페이드,
동일 시드/입력 재현과 240초 차트·기존 입력/물리 회귀.

## 캐릭터 반응 (후속 사용자 지정)

- 색 일치 성공 때 기존 로딩 스프라이트 `player-dog-loading-run-v1.png`의
  가운데 즐겁게 앞발 든 프레임(가로6칸 중4번째, index3)을 재사용한다.
- 성공 포즈와 짧은 점프는320ms, 재성공하면 재시작. 신규 ImageGen 자산은 사용하지 않는다.
- 실제 위치·바닥 피벗·충돌 반지름은 고정하고 렌더만 이동한다.
- 울음은 야구공 충돌 게임오버 순간480ms만 표시한 뒤 결과 화면으로 전환한다.
  Match 생명 소진·일반 Miss·색 일치 성공에는 울음 없음.
- 후속 명시 지정: 충돌 울음은 예전 `player-dog-forbidden-cry-v1.png` 이미지를 재사용한다.
  이 용도에서는 기존 v1 런타임 제외 규칙보다 사용자의 재사용 지정이 우선한다.

## 캐릭터 외형 보정 (2026-09-17 후속 요청)

사용자가 기존 강아지 이미지의 소폭 수정을 명시했다. 앞 절의 신규 ImageGen 자산 금지는
새 성공 포즈를 만들지 말라는 뜻이며, 이번에 승인한 기존 이미지 편집에는 적용하지 않는다.

- 보는 사람 기준 왼쪽 얼굴·눈 주변은 흰색, 오른쪽 얼굴은 검정. 흰 주둥이는 유지.
- 양쪽 귀는 검정이며 기존보다 약간 작게(길이 약15%, 폭 약10% 축소 목표).
- 왼쪽 귀와 얼굴 경계에만 검정이 약간 내려오고 나머지 왼쪽 얼굴은 흰색.
- 기본·울음·로딩6프레임에 같은 외형을 적용하되 기존 자세·표정·동작 역할은 유지한다.
- 기존 마스터는 보존하고 수정본을 별도 버전으로 저장한다. 표시/충돌 크기는 유지한다.
- 편집된 스프라이트의 프레임별 투명 여백 차이를 렌더 좌표로 보정하여 잘림을 방지한다.

## 사용자 직접 표시한 얼굴 경계 (2026-09-17 최종 보정)

직전 외형 보정 중 '왼쪽 얼굴 전체 흰색 / 귀 경계만 조금 검정' 해석은 아래로 대체한다.
사용자가 로딩 네 번째 포즈에 직접 그린 검정 영역을 최우선 시각 기준으로 적용한다.

- 머리 상단은 양쪽 모두 눈 바로 위까지 검정이며 귀 연결부와 이어진다.
- 가운데 좁은 흰 이마선은 유지: 검정 | 흰 줄 | 검정.
- 보는 사람 기준 왼쪽 눈을 포함한 눈 주변과 그 아래 볼은 흰색.
- 왼쪽 검정은 머리 상단에서 관자놀이/얼굴 바깥 경계를 따라 내려온다.
- 오른쪽 눈 주변 검정과 흰 주둥이, 작게 조정한 양쪽 검정 귀는 유지.
- 기본·울음·로딩6자세 모두 같은 무늬를 적용. 사용자의 덧칠은 자연스러운 털로 정리.

후속 자연스러움 보정: 사용자 표시 경계는 유지하면서 검정 영역을 귀와 같은 짙은 차콜 털,
보랏빛 음영·가는 결·부드러운 털 경계로 통일한다. 덧칠 같은 평평한 검정과 과도한 청록/파랑
외곽 광택을 줄인다. 자세·표정·점무늬·게임 판정은 변경하지 않는다.

최종 미세 보정: 보는 사람 기준 왼쪽 관자놀이의 검정 털이 왼쪽 눈 바깥쪽 경계 일부에
직접 닿도록 한다. 사이에 흰 틈을 두지 않되 눈 전체를 검정으로 감싸지 않는다.
눈 아래/안쪽과 볼의 흰색, 중앙 흰 이마선, 자연스러운 털 결과 음영은 유지한다.
