# 게임 기획

게임 규칙, 플레이 흐름, 범위, 수치와 인수 기준을 관리한다.

첫 구현 기준선과 인수 기준을 작성한 단계다. 실제 음악과 최종 자산은 후속 디자인 작업으로 남기고, 정확한 plan 커밋을 개발에 채택해 구현한다.

## 기획 시작점

- [초기 기획 개요](project-brief.md): 게임의 목표, 핵심 경험, 첫 개발 범위와 미결정 항목
- [동시 플레이 게임 기획](gameplay.md): 회피·타이밍·색 전환 규칙과 조작 제안
- [점수와 플레이어 경쟁](scoring-and-leaderboard.md): 생존·판정 점수의 융합과 리더보드 단계
- [인터페이스·비주얼 디자인 플랜](visual-design.md): 화면 구조, 캐릭터, 점·원·링, 색상, HUD, 판정과 게임 오버 연출
- [개발 인계 계약 초안](development-contract.md): 구현 범위, 인수 기준과 착수 조건
- [기술 설계](../architecture/README.md): 제품 결정에 따른 플랫폼·엔진·인터페이스 설계

기획 개요 → 규칙과 범위 검토 → 기술 설계 → 인수 기준 확정 → 정확한 plan 커밋 인계 순으로 진행한다. 초기 문서 생성 자체는 제품 결정 승인이나 개발 착수 승인이 아니다.
