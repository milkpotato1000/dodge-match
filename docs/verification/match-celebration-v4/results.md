# MATCH!!! 효과와 시작 화면

채택 plan09102a7. 사용자 요청에 따라 발판 색 일치 정상 판정은
PERFECT/GREAT/GOOD × MATCH!!!와 SCORE×2를 함께 표시한다.
700ms 내 짧은 확대·상승·페이드와 원형 펄스를 사용하며 Reduced Effects는 확대/이동/펄스 생략.
가장자리 문구가 보드 밖으로 나가지 않도록 위치를 제한한다.
시작 화면의 현재 강아지를 제목 옆으로 옮겨 설정·시작 버튼과 분리해 표시한다.

단위48개, TypeScript/Vite build, Chrome 브라우저10개 통과.
실제 색 일치 클릭에 PERFECT × MATCH!!! 존재 확인. 프로덕션/오프라인의 시작 이미지 로드 확인.
기존 키보드·모바일 동시입력·충돌/생명소진 반응 회귀 통과.
